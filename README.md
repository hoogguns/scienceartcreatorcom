# Science Art Creator

A studio for scientific figures. Drag cells, glassware, and pathways onto a page, label them, and export PNG, SVG, or a print PDF.

The first commit on this repo was a small canvas (rectangles, circles, text). This tree is the combined studio: that canvas, plus the icon library, drafts, saving, and pricing.

Open the studio, choose an icon or press Arrange, then export from the side panel.
